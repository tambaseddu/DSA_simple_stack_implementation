# Stack Expression Calculator

Course: DCOMP320 Data Structures and Algorithm
Assignment: Stacks Implementation

## Run the program
1. Install Python 3 if needed. No third-party packages are required.
2. Extract this folder and keep calculator.py and input.txt together.
3. In VS Code, open this folder and choose Terminal > New Terminal.
4. Run `python calculator.py` (or `py calculator.py` on Windows).
5. Open output.txt to see the results. Each run replaces this file.

The input and output paths are resolved relative to calculator.py, so the program
also works when launched from a different working directory.

## Files
- calculator.py: source code, aligned with Lecture 3.
- input.txt: the original 17-expression test dataset.
- output.txt: output generated by the program.
- README.md: these instructions.

## Input and output
Use one expression per line. Dash-only lines of at least three dashes are
separators, for example `-----`. Separator lines and blank lines are preserved.
Expressions are replaced by answers or descriptive error messages.

Example input:
```
3 + 5 * 2
-----
(8 / 4) + 7 * 2
-----
10 - (2 + 3) * 4
```
Example output:
```
13
-----
16
-----
-10
```
The brief prints 17 for the second expression, but 8 / 4 + 7 * 2 = 16.

## Algorithm and connection to the lessons
The fixed-capacity Stack class uses size, stack and top, following Lecture 3.
It implements push, pop, peek and is_empty, with overflow and underflow checks.
The calculator tokenizes infix input, converts it to postfix with an operator
stack, and evaluates postfix with a value stack. It does not use eval().
Equal-precedence operators are processed from left to right.

## Assumptions and limitations
- Supports non-negative numeric literals, decimals, +, -, *, / and parentheses.
- Negative results are supported. Unary signs such as -5 or +3 are not supported;
  use (0 - 5) to express a negative operand.
- Multiplication must be explicit: use 2 * (3 + 4), not 2(3 + 4).
- Variables, powers, scientific notation and functions are outside the scope.
- Uses binary floating point, so intermediate decimals may be approximate.
- Displays at most four decimal places; this may display a very small result as 0.
- Non-finite numbers/results and division by zero are rejected.
- An invalid expression does not stop processing later lines.
- File-system errors are reported in the terminal.
